QUICK REFERENCE - HOW TO RUN & DEPLOY
================================================================================

⚡ 3-MINUTE QUICK START
================================================================================

STEP 1: Download Node.js
   → Go to: https://nodejs.org/
   → Download LTS version
   → Install it

STEP 2: Extract Project
   unzip data-parser-studio.zip
   cd data-parser-studio

STEP 3: Install & Run
   npm install        (wait 2-3 minutes)
   npm run dev        (opens http://localhost:3000)

STEP 4: Test
   - Click "URL" tab
   - Paste: https://api.github.com/users/github
   - Click "Fetch"
   - See tree view! ✅

DONE! App is running locally.

================================================================================
VERCEL DEPLOYMENT (STEP BY STEP)
================================================================================

FASTEST & EASIEST METHOD:

1. Install Vercel CLI:
   npm install -g vercel

2. Deploy:
   vercel --prod

3. Follow prompts:
   - Press "y" for all questions
   - Your app deploys in ~2 minutes

4. Get URL:
   → https://your-app-name.vercel.app
   → Share this link!

5. Optional - Custom Domain:
   - Go to Vercel dashboard
   - Select project
   - Settings → Domains
   - Add your domain

TIME: 5 minutes ⏱️
COST: Free
RESULT: Production-ready app online ✅

================================================================================
GITHUB PAGES DEPLOYMENT (STEP BY STEP)
================================================================================

EASIEST IF YOU ALREADY HAVE GITHUB:

1. Build:
   npm run build

2. Deploy to GitHub Pages:
   npm install --save-dev gh-pages
   npm run deploy

3. Enable in GitHub:
   - Go to: github.com/yourusername/advanced-data-parser
   - Settings → Pages
   - Select "gh-pages" branch
   - Save

4. Get URL:
   → https://yourusername.github.io/advanced-data-parser
   → Live in 5 minutes!

TIME: 10 minutes ⏱️
COST: Free forever
RESULT: GitHub-hosted app ✅

================================================================================
NETLIFY DEPLOYMENT (STEP BY STEP)
================================================================================

BEST WITH AUTO-DEPLOY:

1. Push to GitHub:
   git add .
   git commit -m "Initial commit"
   git push origin main

2. Connect to Netlify:
   - Go to: https://app.netlify.com
   - Click "New site from Git"
   - Select GitHub & your repo
   - Build: npm run build
   - Publish: dist
   - Click "Deploy"

3. Auto-Deploy Setup:
   - Every push to GitHub = auto-redeploy
   - No manual deployment needed

4. Get URL:
   → https://your-site-name.netlify.app
   → Live in 3 minutes!

TIME: 15 minutes ⏱️
COST: Free
RESULT: Auto-deploying app ✅

================================================================================
COMMON ISSUES & FIXES
================================================================================

ISSUE: "npm: command not found"
FIX:   Install Node.js from https://nodejs.org/

ISSUE: Port 3000 already in use
FIX:   npm run dev -- --port 3001

ISSUE: "Module not found"
FIX:   npm install

ISSUE: Build fails
FIX:   rm -rf node_modules && npm install && npm run build

ISSUE: CORS error in production
FIX:   Check "Use CORS proxy" checkbox in app

ISSUE: Large files won't upload
FIX:   Max size is 50MB, split or use URL method
